## LIVE-VERIFY — DONE 2026-06-01 (confirmed against live APIs with owner's keys)
- **Tavily** (topic=news): result has `score` (float, e.g. 0.9966234) AND
  `published_date` (string) → tag `json:"published_date,omitempty"`. **FORMAT =
  RFC1123** e.g. `"Tue, 19 May 2026 18:59:59 GMT"` (day-name + GMT, NOT ISO).
- **Brave** (freshness=pm): result has `page_age` = `"2026-06-01T02:34:19"`
  (**zoneless ISO, no Z**) and `age` = `"6 hours ago"` (relative, unparseable —
  prefer page_age). Tags `json:"page_age,omitempty"` / `json:"age,omitempty"`.
  Brave exposes NO relevance score → Score stays nil.
- **recency.go layouts MUST include (in order):** `time.RFC1123`,
  `time.RFC1123Z`, `time.RFC3339`, `time.RFC3339Nano`,
  `"2006-01-02T15:04:05.000Z"`, `"2006-01-02T15:04:05"` (Brave page_age),
  `"2006-01-02"`. Missing RFC1123 would silently demote every Tavily date.
